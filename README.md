# AutoSeries Studio (เว็บ — GitHub + Netlify)

เว็บแอปสร้างซีรีส์คลิปสั้นต่อเนื่อง: Gemini Flash เขียนบท/prompt → คุณสร้างคลิปใน Flow → ติ๊กความคืบหน้า
ไม่มี backend ทำงานในเบราว์เซอร์ทั้งหมด (ยังไม่ตัดต่อรวมคลิปให้)

## อัปขึ้น GitHub (ทำจากมือถือได้)
1. สร้าง repository ใหม่บน github.com
2. Add file → Upload files → เลือกไฟล์ทั้งหมดในโฟลเดอร์นี้ (ไฟล์อยู่ระดับเดียวกัน ไม่มีโฟลเดอร์ย่อย) → Commit

## ใช้งานผ่าน Netlify
1. app.netlify.com → Add new site → Import an existing project → GitHub → เลือก repo
2. Build command: เว้นว่าง / Publish directory: `.` → Deploy
3. เปิดลิงก์ที่ได้บนมือถือ → เมนูเบราว์เซอร์ → "เพิ่มไปยังหน้าจอโฮม"

## ใช้ครั้งแรก
แท็บ "ตั้งค่า" → ใส่ Gemini API key (ขอฟรีที่ aistudio.google.com) และชื่อโมเดล (ค่าเริ่มต้น `gemini-3-flash-preview` ถ้าไม่ได้ให้ใช้ชื่อ Flash ที่เห็นใน AI Studio) → ทดสอบคีย์

## ข้อควรรู้
- API key และข้อมูลเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น (localStorage) ไม่ขึ้นเซิร์ฟเวอร์ ข้อมูลไม่ซิงก์ระหว่างเครื่อง → ใช้ "สำรองข้อมูล/นำเข้า" ในตั้งค่า
- ล้างข้อมูลเบราว์เซอร์ = ข้อมูลหาย ควรสำรองเป็นระยะ
- อย่าใส่ API key ในโค้ดหรือ repo
- ระดับฟรีของ Gemini อาจใช้ prompt ไปพัฒนาโมเดล อย่าใส่ข้อมูลส่วนตัว
- วิดีโอ Flow ฟรีมีลายน้ำและเงื่อนไขการใช้ ตรวจเงื่อนไขของ Google
