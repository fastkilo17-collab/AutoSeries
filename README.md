# AutoSeries Studio

ไฟล์หลักคือ `index.html` ไฟล์เดียว (โค้ด สไตล์ โลโก้ รวมอยู่ข้างใน และถูกย่อ/ล็อกให้อ่านยาก)
อัปขึ้น GitHub แล้วเชื่อม Netlify ได้เลย ต้องอัป `netlify.toml` ด้วยทุกครั้ง (ใน `netlify.toml` มีค่ารับรองสคริปต์ที่ตรงกับ index.html ฉบับนั้นพอดี ถ้าอัปไม่คู่กันหน้าจะขาว)
`manifest.webmanifest`, `icon-192.png`, `icon-512.png` ไม่บังคับ ใส่ไว้เพื่อให้ติดตั้งเป็นแอปบน Android ได้เต็มรูปแบบ

ขั้นตอนใช้งาน ตั้งค่า API key และตั้งค่า Google Drive ดูในไฟล์ README เดิม (ขั้นตอนไม่เปลี่ยน)
